# Rookie Season

A beginner's guide to picking a sports team and learning how the game works: team finders, team pages, players, maps, rules and quizzes for about 90 leagues.

The site is three static files (`index.html`, `site.js`, `styles.css`) and needs no build step to host. It is served with GitHub Pages from the `main` branch.

Rookie Season is not affiliated with any league or team.
